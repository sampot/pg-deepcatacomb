# 深窟探險 (`pg-deepcatacomb`)

六層程序生成地城的傳統回合制 Roguelike。你走一步、地城跟著動一步；火把只照亮七格，飢餓一直在掉，死了就從第一層重來。

類型：**傳統 Roguelike** · 系列：策略

## 玩法

- **一步一動：** 按方向鍵（或 `WASD`／`hjkl`）、點自己旁邊的格子、在盤面上滑一下，或用畫面下方的十字鍵。你動一步之後，怪物才動。
- **走過去就是打：** 走向怪物即近戰攻擊。傷害＝攻擊＋隨機值−對方防禦，至少 1 點。怪物看到你就會一路追。
- **視野：** 沒去過的地方全黑，走過的地方留在記憶裡但變暗（看得到地形與撿過的道具，看不到怪物），火把照到的七格才是明亮的當下。
- **飢餓：** 每回合掉 1 點，歸零就餓死。原地等待每 12 回合回 1 點體力——療傷的代價就是糧食。
- **裝備與消耗品：** 踩過的東西自動收下。武器與護甲只有比身上的好才會換裝；藥水回 16 點體力，乾糧補 180 點飢餓。
- **升級：** 擊殺累積經驗，升級 +5 血上限、+1 攻擊，偶數等再 +1 防禦。
- **通關條件：** 一路下到第六層的王座大廳，**斬殺骸骨王**。體力歸零或餓死即結束，最深層數與最高分會留下來。

怪物依深度出現：窟鼠、洞蝠 → 哥布林、骷髏兵 → 腐屍、毒蠍 → 獸人 → 幽魂、石魔 → 骸骨王。腐屍與石魔兩回合才走一步，洞蝠會亂飛。

鍵盤：方向鍵／`WASD`／`hjkl` 移動，`空白鍵`或 `.` 等待，`>` 或 `Enter` 下樓，`q` 喝藥水，`e` 吃乾糧。

## 遊玩

純 HTML／CSS／JavaScript，無 build 步驟。本機開 `index.html`，或經 Playgrounds／go 安裝。最深層數、最高分與**進行中的那一趟**（地圖、視野、背包、怪物位置）透過 `/api/kv/` 由宿主保存，關掉再回來可以續探。

## 開發

```bash
npx vitest run
```

`game.js` 是無 DOM 的純邏輯（地城生成、視野、移動、戰鬥、飢餓、道具、樓梯、勝負判定），同一 seed 必得同一局；`app.js` 只負責 canvas 繪製、輸入與音效。
